# Kokpit

Skywell ET5 için Kokpit uygulaması.

## Araçta kurulum

1. Kokpit > Uygulamalar > Tarayıcı ile bu sayfayı aç.
2. Aşağıdaki bağlantıya dokun:

### [Kokpit.apk'yı indir](https://github.com/emreyucell2016-stack/kokpit-indir/raw/main/Kokpit.apk)

3. "APK indirilsin mi?" sorusuna İndir, ardından Kur de.

iPhone ekranını yansıtmak için: [AirPlay Server (F-Droid)](https://f-droid.org/packages/io.github.jqssun.airplay/)
